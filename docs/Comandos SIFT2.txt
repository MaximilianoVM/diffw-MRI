Estimación de la función de respuesta

dwi2response tournier \
ISMRM_2023_b3000.nii.gz \
response.txt \
-fslgrad ISMRM_2023_b3000.bvec \
ISMRM_2023_b3000.bval \
-mask ISMRM_2023_b3000_mask.nii


Generación de las FOD mediante CSD

dwi2fod csd \
ISMRM_2023_b3000.nii.gz \
response.txt \
ODF.nii \
-fslgrad ISMRM_2023_b3000.bvec \
ISMRM_2023_b3000.bval \
-mask ISMRM_2023_b3000_mask.nii


Aplicación de SIFT2

tcksift2 \
../../Fibers/tck/all_tracks.tck \
ODF.nii \
weights.txt \
-out_mu mu.txt
